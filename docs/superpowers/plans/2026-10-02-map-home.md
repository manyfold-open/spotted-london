# Map home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Explore and Map with one full-screen map home that answers "what is near me", with a Map | List switch, a hamburger menu instead of the sidebar and tab bar, and a share-location flow.

**Architecture:** One `HomePage` route renders a lazy `PopupMap` under floating chrome (`TopBar`, chips, `MapSheet`, locate and Add buttons). Position and mode are small hooks; the list is still the single snapshot filtered in the browser. `Shell` loses `aside` and `tabbar` and renders `NavMenu` plus the right bar for the route.

**Tech Stack:** Vite, React 19, React Router 8 (library mode), TanStack Query, MapLibre 6, plain CSS in `web/src/styles.css`, vitest in workerd for pure helpers.

Spec: `docs/superpowers/specs/2026-10-02-map-home-design.md`. Read its "No-overlap rules" before touching CSS.

## Global Constraints

- UI copy is plain English: no em dashes, en dashes or spaced hyphens. Errors say what happened and what to do.
- Phone layout is under 900 px (`@media (max-width: 899px)`). Check every screen at 375 px.
- Inputs are 16 px on phones. No native browser UI.
- New CSS classes are prefixed `mp-`; `.drawer`, `.scrim`, `.panel`, `.me`, `.nav`, `.search`, `.toast` already mean other things.
- Z-index: map chrome under 20, pop-up sheet and its scrim 20 to 21, menu 22 and its scrim 22.
- Motion goes through `reducedMotion()` from `web/src/lib/motion.ts`; durations use `--dur-*`, easings `--ease-out` and `--ease-spring`.
- Map pins stay plain DOM (not React roots). MapLibre worker stays set through `setWorkerUrl` in `maps.tsx`.
- The public list stays the same for everyone; position never goes to the server.
- Commands: `npm run typecheck && (cd web && npx tsc --noEmit)`, `npm test`, `npm run build:web`.
- Branch `feat/map-home`; open a PR, Zack merges. No migration, so no D1 step.

```ts
// Pure decisions for the map home, kept out of React so they can be tested.

export type Snap = 'peek' | 'half' | 'full';

/** Where a dragged sheet settles. A fast flick adds 180 ms of travel at its release speed. */
export function pickSnap(y: number, velocity: number, heights: Record<Snap, number>): Snap {
  const landing = y + velocity * 180;
  let best: Snap = 'peek', gap = Infinity;
  for (const s of ['full', 'half', 'peek'] as const) {
    const d = Math.abs(heights[s] - landing);
    if (d < gap) { gap = d; best = s; }
  }
  return best;
}

/** The map counts as panned away from you when your dot is this far (px) from the visible centre. */
export function isAway(dx: number, dy: number, threshold = 70): boolean {
  return Math.hypot(dx, dy) > threshold;
}

/** What to do about location when the home page opens. */
export function nearMeStart(permission: PermissionState | 'unknown', stored: '1' | '0' | null): 'auto' | 'prompt' | 'none' {
  if (permission === 'denied' || stored === '0') return 'none';
  if (permission === 'granted' && stored === '1') return 'auto';
  return 'prompt';
}
```

  ```ts
  function useNearMe(): {

    prompt: boolean;               // show the "Pop-ups near you?" card
    filter: boolean;               // the Near me chip is on
  ```

- [ ] **Step 2: Write `near-me.ts`.** Initial effect: read `localStorage` and `navigator.permissions?.query({ name: 'geolocation' })`, call `nearMeStart`; `'auto'` calls `request()`, `'prompt'` sets `prompt = true`, `'none'` does nothing (and a `denied` permission sets `state = 'denied'`). `request()` sets `state = 'asking'`, awaits `currentPosition()`, on success sets `pos`, `state = 'on'`, `filter = true`, `prompt = false`, stores `'1'`; on failure sets `state = 'denied'` when the browser said blocked (error message from `currentPosition` contains "Allow location"), otherwise back to `'idle'`, rethrows nothing but returns `null` and calls `useErrorToast()` with the error. If `navigator.geolocation` is missing, `state = 'unsupported'`.
